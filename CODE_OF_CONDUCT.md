# Código de conducta

## Principios

Este proyecto invita a contribuir con respeto, profesionalismo y argumentos verificables. Se espera colaboración constructiva, revisión técnica fundamentada y comunicación clara sobre errores y limitaciones.

No se toleran acoso, amenazas, hostigamiento, divulgación de datos privados, discriminación o ataques personales en Issues, pull requests, discusiones o espacios vinculados al proyecto.

## Reportes y moderación

Si observas una conducta inapropiada, utiliza los mecanismos de reporte de GitHub y comunícate con el mantenedor por los canales disponibles sin exponer datos sensibles. Para vulnerabilidades de seguridad sigue exclusivamente [SECURITY.md](SECURITY.md).

Las medidas pueden incluir advertencias, cierre de discusiones, rechazo de contribuciones y restricciones de participación, según el caso. Este documento no constituye un servicio de moderación con plazos garantizados.
